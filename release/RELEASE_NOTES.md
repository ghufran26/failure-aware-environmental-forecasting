# Failure-aware environmental forecasting: research artifact v1.0.0

Code and recorded experimental outputs for *Failure-Aware Environmental Forecasting Under Missing, Faulty, and Shifted Sensor Data*.

The repository provides the Kaggle-compatible notebook, twelve original Python modules, experiment configurations, dataset instructions, publication figures, tables, plot data, and run manifests. The attached `primna-tom-res.zip` contains the complete supplied dissemination outputs, including detailed numeric results.

The supplied run records phases 1–10 as complete and 13 regression checks passed. Packaging checks verified all 2,099 output-manifest entries and agreement between the twelve archived source modules and the supplied notebook. A new scientific rerun was not performed during packaging.

All evaluations are retrospective. The archived rare false-alarm claim is unsupported at its target rate; interval coverage is empirical, and energy telemetry was unavailable. Raw datasets are acquired from the official UCI sources documented in the repository.

Refer to `release/SHA256SUMS` for the original uploaded ZIP checksum. This release does not assert journal acceptance or supply resumable checkpoints.
